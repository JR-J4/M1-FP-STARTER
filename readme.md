Caesar Cipher Cryptanalyzer

Программа выполняет шифрование и расшифровку текста с использованием шифра Цезаря, работает с файлами и
поддерживает автоматический подбор ключа (brute force).

Что удалось реализовать:
- Шифрование текста (-e)
- Расшифровка текста (-d)
- Поддержка произвольного ключа
- Работа с файлами .txt
- Создание нового файла без изменения исходного
- Автоматическое формирование имени выходного файла:
  file.txt → file [ENCRYPTED].txt
  file [ENCRYPTED].txt → file [DECRYPTED].txt
- Перебор ключей (-bf) для восстановления исходного текста
- Поддержка английского и украинского алфавитов
- Автоматическое определение языка текста
- Обработка ошибок без завершения программы исключением

Что не удалось реализовать:
- Частотный анализ

Особенности проекта:
- Архитектура разделена по зонам ответственности:
- ArgumentParser — разбор аргументов командной строки
- Cipher — логика шифрования
- BruteForce — подбор ключа
- FileService — работа с файлами
- LanguageDetector — определение языка
- Основная логика не зависит от способа запуска программы.

Интересные решения:
- Реализован автоматический выбор алфавита (английский / украинский)
- Brute force использует словарный подход для выбора наиболее вероятного результата
- Поддержан произвольный порядок аргументов командной строки

Пример запуска:
Шифрование:
java -jar target/J4-M1-FP-1.0-SNAPSHOT.jar -e -k 5 -f input.txt
Расшифровка:
java -jar target/J4-M1-FP-1.0-SNAPSHOT.jar -d -k 5 -f input.txt
Brute force:
java -jar target/J4-M1-FP-1.0-SNAPSHOT.jar -bf -f input.txt
