

Криптоаналізатор Шифру Цезаря
Це консольна програма (CLI) на Java для шифрування, 
розшифрування та злому (криптоаналізу) тексту, 
зашифрованого за допомогою шифру Цезаря. 
Програма підтримує роботу з текстовими файлами та автоматично розпізнає мову тексту.

🌟 Основні можливості
Два режими роботи: Запуск із параметрами командного рядка (CLI) або 
через інтерактивне меню.

Підтримка двох мов: Англійська (ENG) та Українська (UKR).
Мова визначається автоматично на основі вмісту файлу.

Збереження форматування: Програма змінює лише літери алфавіту. 
Усі інші символи (пробіли, розділові знаки, цифри) залишаються без змін.

Автоматичне найменування файлів: Результати зберігаються у нові файли 
з відповідними суфіксами ([ENCRYPTED], [DECRYPTED], [BRUTE_FORCE]), 
що запобігає втраті оригінальних даних.

Частотний криптоаналіз (Brute Force): Програма здатна автоматично підібрати ключ шифрування, 
спираючись на частоту використання літер у тексті
(найчастіша літера 'e' для англійської та 'о' для української).

🚀 Як користуватися
Програму можна запустити двома способами: передавши аргументи при запуску (CLI) 
або запустивши її без аргументів для переходу в інтерактивний режим.

Формат команд
Програма приймає наступні прапорці (флаги):

-e : Зашифрувати файл (Encrypt).

-d : Розшифрувати файл (Decrypt).

-bf: Зламати шифр методом частотного аналізу (Brute Force). Ключ не потрібен.

-k <число> : Ключ шифрування (ціле число). Обов'язковий для -e та -d.

-f <шлях> : Шлях до файлу, який потрібно обробити.

💻 Приклади команд
1. Шифрування тексту
   Щоб зашифрувати текст у файлі text.txt з ключем 5:

java -jar M1-FP-Mykhailo.jar -e -k 5 -f "C:\path\to\text.txt"
Результат: З'явиться новий файл text[ENCRYPTED].txt із зашифрованим текстом.

2. Розшифрування тексту
   Щоб розшифрувати файл text[ENCRYPTED].txt за допомогою відомого ключа 5:


java -jar M1-FP-Mykhailo.jar -d -k 5 -f "C:\path\to\text[ENCRYPTED].txt"
Результат: З'явиться файл text[DECRYPTED].txt.

3. Автоматичний злом (Brute Force)
   Якщо ви не знаєте ключа, програма спробує знайти його автоматично:


java -jar M1-FP-Mykhailo.jar -bf -f "C:\path\to\text[ENCRYPTED].txt"
Результат: Програма знайде правильний зсув та збереже результат у файл text[BRUTE_FORCE].txt.

📁 Структура проєкту
ua.com.javarush.j4.alphabet — Містить перелічення (Enum) 
з українським та англійським алфавітами, 
а також логіку для автоматичного визначення мови.

ua.com.javarush.j4.args — Класи для парсингу аргументів командного рядка (ArgsParser, RunOptions).

ua.com.javarush.j4.cipher — Основна логіка шифрування (Cipher) 
та злому методом частотного аналізу (BruteForce).

ua.com.javarush.j4.file — Допоміжний сервіс для читання 
та запису текстових файлів (FileService).

ua.com.javarush.j4.menu — Логіка керування потоком програми 
(інтерактивне меню та обробка команд).

ua.com.javarush.j4.Main — Точка входу в програму.

🧠 Особливості реалізації
У цьому проєкті реалізовано кілька нестандартних рішень 
для підвищення зручності та ефективності програми:

1. Частотний аналіз (Brute Force)
Замість класичного перебору всіх можливих зсувів алфавіту, 
алгоритм у класі BruteForce використовує розумний метод частотного аналізу:

Програма сканує зашифрований текст та створює мапу (HashMap) частоти появи кожної літери.
Знаходить літеру, яка зустрічається найчастіше.
Зіставляє її з найпопулярнішою літерою визначеної мови 
('e' для англійської та 'о' для української).
Математично вираховує оригінальний ключ (зсув)
на основі різниці індексів цих літер в алфавіті, 
після чого миттєво розшифровує текст.

2. Гнучке керування (MainMenu)
Клас MainMenu підтримує два режими роботи, 
які автоматично перемикаються залежно від того, як була запущена програма:

Terminal Mode (startTerminal): Якщо програма отримує аргументи при запуску, 
вона відразу виконує команду та завершує роботу.

Scanner Mode (startScanner): Якщо користувач запускає програму без аргументів, 
вона не падає з помилкою, а відкриває інтерактивне консольне меню (do-while цикл). 
У цьому режимі можна вводити команди одну за одною, не перезапускаючи програму щоразу, 
аж поки не буде введена команда exit.
